# AndroidHiddenApiBypass

版本：6.2，Apache-2.0，Copyright LSPosed。

官方项目：https://github.com/LSPosed/AndroidHiddenApiBypass

下载来源：https://repo.maven.apache.org/maven2/org/lsposed/hiddenapibypass/hiddenapibypass/6.2/hiddenapibypass-6.2.aar

AAR SHA-256：`DCDBD6FC8F70D722B06700CBE30888DED5D329BC3088D3AD92DEDDBDC8895DB3`。

JAR 直接提取自该 AAR 的 classes.jar，未修改。许可证保存在本目录并打包到 APK。
仅对本应用进程开放 BluetoothDevice 的反射访问，不安装 Xposed，不改系统蓝牙进程，不授予系统权限。

JAR/AAR 是本地构建输入，不上传源码仓库。JAR 与原 AAR 哈希固定在根目录 third_party/dependencies.json；克隆后按该清单恢复。
