# LinkPods v1.1 / build102 — 预发布

本版本以最新 main 的第一阶段控制会话及审查修复为基础，发布同签名 APK。应用版本升为 1.1，versionCode 从 101 升为 102；包名仍为 lp.pods，支持覆盖升级。安装文件与 SHA-256 校验文件见 [v1.1 Release](https://github.com/NortonLi0202/LinkPods/releases/tag/v1.1)。

## 本次更新

- 独立控制会话（CONTROL_ONLY）可在未开启自动交接、未授权媒体会话访问时连接、读取状态并控制耳机。
- CONTROL_ONLY 与 AUTO_HANDOFF 共享控制连接；模式切换重置旧路由意图，不主动暂停媒体或断开现有 A2DP。
- 模式升级时补发已知对端通告，提前同步本机蓝牙地址；退出再进入自动交接后，旧队列中的路由包不会因模式重新开启而恢复有效。
- 媒体监听启动失败时清理部分注册的回调；重启监听保留待处理 TAKE 并重新同步媒体状态。
- 分开展示系统音频、耳机控制和自动交接状态；界面重建后的桥接准备保留当前所选模式。
- 保留多代 AirPods 的型号识别、能力门控与未知状态展示。

## 安装与兼容

Android 12L/API32 及以上、ARM64。使用现有签名身份，覆盖升级保留原应用数据。直连优先；桥接仍须精确匹配系统适配，已有 Root 不等于蓝牙适配可用。

## 已知限制

这是预发布版本，尚未完成物理耳机控制听感、双向音频、双直播抢回、通话恢复及逐型号/逐固件验收。SM-X810 是首轮验收基线，不表示其所有固件都已支持。AirPods Max 仍按未知型号处理。详见 [已知问题与验收矩阵](../issues/README.md)。

主机测试、APK 构建和签名验证不能替代实际耳机验收。

## 第三方材料

固定来源及现有源码/补丁见 [THIRD_PARTY.md](../../THIRD_PARTY.md)、third_party/sources 和 third_party/payloads/manifest.json。APK 包含已保留的组件许可及来源说明；这不授予新的整体许可，也不表示完成了完整分发审查。私钥、密码、原始设备数据和独立构建输入不进入 Git。
