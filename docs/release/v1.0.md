# LinkPods v1.0 / build101

这是 v1.0 源码快照，不代表全部功能已通过生产稳定性验收。仓库不提供 APK 或私有构建输入。

## 已接入

- 平板分栏与窄窗口单列、浅深色、自绘可拖动噪声胶囊、椭圆开关及当前 Android 媒体音量。
- 耳机回报的电量和标量设置，以及目标/会话隔离、白名单写入、待确认和超时。未知值不伪造，重连后等待新电量通知。
- 从 AACP INFORMATION 专用字段识别固定上游注册表中的多代 AirPods；已知型号按上游能力表限制现有噪声/自适应/对话感知/个性化音量/滑动等控制，未知型号继续使用报告驱动行为。型号元数据在断开、新会话和目标切换时清除；详情见 [多代型号说明](../airpods-models.md)。
- 直连优先且不预先检测 Root；自动回退仅在明确兼容错误时尝试一次已有 Root 桥接。用户也可手动选择准备桥接，无需先出现兼容错误。桥接按注册表精确选择，临时 Root 仍须单独确认。Root、控制通道、所有权与实际音频分别处理。

## 当前限制

当前设置操作依赖已启用的交接服务；独立 control-only 会话、部分高级设置、充电详情和真实背景折射仍未完成。耳机降噪/设置回报、双向音频、双直播抢回和通话恢复尚未完成验收。多代型号注册表和能力门控已通过主机测试，但没有逐型号物理耳机验收；其他手机、固件和 AirPods Max 不能据代码接口推断支持。蓝牙桥接、Root/临时 Root、路由、包名、SDK 下限和 build101 未因型号适配改变。

没有 Root 的设备仅在 compatibility/targets.json 精确匹配时有临时 Root 路线；已有 Root 不等于原生 Bluetooth 适配已可用。minSdk32 和 ARM64 是安装/构建条件，不是兼容保证。

现有主机验证覆盖 Python工具、Java策略/协议/控件安全边界、型号注册表/INFORMATION 解析/能力门控和 Node原生配置，APK 构建验证签名、非调试元数据与固定载荷。主机通过或单次界面安装不能替代实际耳机试听，也不能证明所有型号或固件都发送相同布局。

发布安装包前须补齐对应场景验收及第三方源码/素材/分发材料审查。组件许可见 THIRD_PARTY.md。详细已知问题见 docs/issues/README.md。
