# LinkPods v1.0 / build101

这是 v1.0 源码快照，不代表全部功能已通过生产稳定性验收。仓库不提供 APK 或私有构建输入。

## 已接入

- 平板分栏与窄窗口单列、浅深色、自绘可拖动噪声胶囊、椭圆开关及当前 Android 媒体音量。
- 独立控制会话（CONTROL_ONLY）：允许用户在不授权媒体会话、不启用自动交接的情况下连接、查询并控制耳机（降噪模式与开关设置），并隔离媒体暂停、抢回及 A2DP 断开等副作用。
- 会话模式安全切换：CONTROL_ONLY 与 AUTO_HANDOFF 共享单一 AACP 会话，模式切换时清空旧路由意图，保留耳机控制状态且不断开已连接的音频链路。
- 耳机回报的电量和标量设置，以及目标/会话隔离、白名单写入、待确认和超时。未知值不伪造，重连后等待新电量通知。
- 直连优先且不预先检测 Root；自动回退仅在明确兼容错误时尝试一次已有 Root 桥接。用户也可手动选择准备桥接，无需先出现兼容错误。桥接按注册表精确选择，临时 Root 仍须单独确认。Root、控制通道、所有权与实际音频分别处理。

## 当前限制

独立 control-only 会话已接入，但耳机实际降噪听感回报、部分高级设置、充电详情、双向音频、双直播抢回和通话恢复仍待真机验收。首轮真机验收以 SM-X810 矩阵（T01–T12）为基线。其他手机与固件也不能据代码接口推断支持。

没有 Root 的设备仅在 compatibility/targets.json 精确匹配时有临时 Root 路线；已有 Root 不等于原生 Bluetooth 适配已可用。minSdk32 和 ARM64 是安装/构建条件，不是兼容保证。

现有主机验证覆盖 Python工具、Java策略/协议/控件安全边界和 Node原生配置，APK 构建验证签名、非调试元数据与固定载荷。主机通过或单次界面安装不能替代实际耳机试听。

发布安装包前须补齐对应场景验收及第三方源码/素材/分发材料审查。组件许可见 THIRD_PARTY.md。详细已知问题见 docs/issues/README.md。
